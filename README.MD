#### Документация проекта

##### Обзор

Этот проект представляет собой микросервисное приложение, состоящее из следующих компонентов:

**API Gateway**

**Auth Service**

**Todo Service**

**User Service**

**Frontend (Vue.js)**

**MongoDB (для User Service)**

**PostgreSQL (для Todo Service)**

##### Требования

**Docker**

**Docker Compose**

##### Установка и запуск

**Клонируйте репозиторий:**

```
git clone <URL_репозитория>
cd <директория_проекта>
```

**Создайте файл **.env** в корневой директории проекта и добавьте необходимые переменные окружения (если требуется).**

**Запустите проект с помощью Docker Compose:**

```
docker-compose up --build
```

 Это соберет и запустит все сервисы, включая frontend, базы данных и API Gateway.

**После успешного запуска, сервисы будут доступны по следующим адресам:**

**Frontend: **[http://localhost](http://localhost/)

**API Gateway: **[http://localhost:8080](http://localhost:8080/)

**Auth Service: **[http://localhost:8080/auth](http://localhost:8080/auth)

**Todo Service: **[http://localhost:8080/todos](http://localhost:8080/todos)

**User Service: **[http://localhost:8080/users](http://localhost:8080/users)

##### Данные для авторизации по умолчанию

При первом запуске проекта, система автоматически создает пользователя по умолчанию:

**Email: **[admin@example.com](mailto:admin@example.com)

**Пароль: adminpassword**

Используйте эти данные для первого входа в систему. После входа рекомендуется изменить пароль через интерфейс приложения.

##### Структура проекта

**api-gateway/**: Код API Gateway

**auth-service/**: Код сервиса аутентификации

**todo-service/**: Код сервиса задач

**user-service/**: Код сервиса пользователей

**frontend/**: Код frontend приложения

**docker-compose.yml**: Конфигурация Docker Compose для запуска всех сервисов

##### Разработка

Для разработки отдельных сервисов вы можете запустить их локально:

**Перейдите в директорию сервиса (например, **cd auth-service**)**

**Установите зависимости: **npm install

**Запустите сервис в режиме разработки: **npm run start:dev

##### Тестирование

Каждый сервис содержит свои unit и integration тесты. Для запуска тестов:

**Перейдите в директорию сервиса**

**Выполните команду: **npm test

##### Развертывание

Для развертывания в production среде:

**Обновите переменные окружения в файле **.env** для production.**

**Запустите: **docker-compose -f docker-compose.prod.yml up --build

##### Устранение неполадок

**Если у вас возникли проблемы с подключением к базам данных, убедитесь, что порты 27017 (MongoDB) и 5432 (PostgreSQL) не заняты другими процессами.**

**При проблемах с CORS, проверьте настройки в API Gateway и frontend приложении.**
